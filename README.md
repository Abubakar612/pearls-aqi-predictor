# Pearls AQI Predictor

AI-powered Air Quality Index forecasting system.

## Objective

Predict the Air Quality Index for the next 72 hours using weather and air pollution data.

## Technology Stack

- Python
- FastAPI
- HTML/CSS/JavaScript
- Scikit-learn
- TensorFlow
- Hopsworks
- SHAP
- GitHub Actions
